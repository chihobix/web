Introduction to XML

XML (eXtensible Markup Language) is a markup language designed for storing and transporting data. It is both human-readable and machine-readable, making it highly versatile for various applications such as web services, configuration files, and document storage.

External DTD

An External DTD (Document Type Definition) allows you to define XML structure and rules in a separate file. This promotes reusability and cleaner XML files.

            
                !ELEMENT note (to, from, heading, body)
                !ELEMENT to (#PCDATA)
                !ELEMENT from (#PCDATA)
                !ELEMENT heading (#PCDATA)
                !ELEMENT body (#PCDATA)

Example of using an external DTD in an XML file:

            
                
                
                
                    John
                    Jane
                    Reminder
                    Don't forget the meeting!

Standalone XML Documents

Standalone XML documents are self-contained and do not reference external DTDs or other resources. The `standalone` attribute in the XML declaration specifies whether the document relies on external declarations.

            
                
                
                    John
                    Jane
                    Reminder
                    Don't forget the meeting!

XML Methods

Here are some common methods used in XML processing:

1. Parsing XML with DOM

The DOM (Document Object Model) parser loads the entire XML document into memory, allowing manipulation of elements and attributes.

            
                const parser = new DOMParser();
                const xmlString = `
                    
                        John
                        Jane
                        Reminder
                        Don't forget the meeting!
                    `;
                const xmlDoc = parser.parseFromString(xmlString, "text/xml");
                console.log(xmlDoc.getElementsByTagName("to")[0].textContent);

2. Using XPath

XPath is used to navigate XML documents and retrieve specific elements or attributes.

            
                const evaluator = new XPathEvaluator();
                const result = evaluator.evaluate("//note/to", xmlDoc, null, XPathResult.ANY_TYPE, null);
                const node = result.iterateNext();
                console.log(node.textContent); // Outputs "John"
