HTML Events

Event Name Category Description Supported HTML Tags W3Schools Link
click Mouse Events Occurs when an element is clicked. <button>, <a>, <div>, etc. click Event
dblclick Mouse Events Occurs when an element is double-clicked. <button>, <a>, <div>, etc. dblclick Event
mouseover Mouse Events Occurs when the pointer is moved onto an element. <div>, <a>, <button>, etc. mouseover Event
mouseout Mouse Events Occurs when the pointer is moved out of an element. <div>, <a>, <button>, etc. mouseout Event
keydown Keyboard Events Occurs when a key is pressed down. <input>, <textarea>, <body>, etc. keydown Event
keypress Keyboard Events Occurs when a key is pressed and held. <input>, <textarea>, <body>, etc. keypress Event
keyup Keyboard Events Occurs when a key is released. <input>, <textarea>, <body>, etc. keyup Event
load Window Events Fires when the page has finished loading. <body>, <img>, etc. load Event
resize Window Events Fires when the browser window is resized. <window> resize Event
scroll Window Events Occurs when an element is scrolled. <window>, <div> scroll Event
submit Form Events Occurs when a form is submitted. <form> submit Event
change Form Events Occurs when the value of an element is changed. <input>, <select>, <textarea> change Event
focus Form Events Occurs when an element gets focus. <input>, <select>, <textarea> focus Event
blur Form Events Occurs when an element loses focus. <input>, <select>, <textarea> blur Event
input Form Events Fires when the value of an element is changed. <input>, <textarea> input Event
dragstart Drag Events Occurs when the user starts dragging an element. <img>, <div>, etc. dragstart Event
drag Drag Events Occurs when an element is being dragged. <img>, <div>, etc. drag Event
drop Drag Events Occurs when an element is dropped. <img>, <div>, etc. drop Event
copy Clipboard Events Fires when the user copies content. <input>, <textarea> copy Event
cut Clipboard Events Fires when the user cuts content. <input>, <textarea> cut Event
paste Clipboard Events Fires when the user pastes content. <input>, <textarea> paste Event
